# PACMAN3 - FPGA吃豆人游戏（Verilog实现）

基于Verilog硬件描述语言实现的经典吃豆人游戏，适配Cyclone IV E FPGA开发板。
项目采用PS2键盘作为输入设备，集成音乐播放模块与七段数码管显示，实现完整的视听游戏体验。

================================================================================
项目特点
================================================================================

PS2键盘控制      专用PS2协议控制器，支持方向键控制Pac-Man移动，独立按键控制暂停/继续
音乐模块          独立Music_Player模块，生成游戏音效与背景音乐
VGA实时渲染       4级硬件流水线渲染引擎，精灵ROM独立存储（墙体/吃豆人/幽灵）
多难度地图        通过拨动开关切换地图布局，mif格式存储
LFSR随机数        线性反馈移位寄存器，为幽灵AI提供随机行为种子
七段数码管        实时显示分数与游戏状态
纯硬件实现        无软核处理器，全逻辑电路驱动

================================================================================
开发环境
================================================================================

IDE:        Quartus II 13.1
FPGA:       Cyclone IV E (EP4CE6E22C8)
输入设备:    PS2标准键盘
音频输出:    蜂鸣器/扬声器（PWM驱动）
显示输出:    VGA接口，分辨率 640x480@60Hz
辅助显示:    板载七段数码管

================================================================================
快速开始
================================================================================

1. 克隆仓库
   git clone https://github.com/你的用户名/PACMAN3.git
   cd PACMAN3

2. 导入Quartus
   - 打开 Quartus II 13.1
   - File -> Open Project -> 选择 PACMAN3.qpf
   - 确认工程文件列表包含所有 .v 和 .mif 文件

3. 关键配置检查
   - 确认 Pin Planner 中PS2时钟线（PS2_CLK）和数据线（PS2_DATA）已正确分配
   - 确认音频输出引脚已绑定到板载蜂鸣器或音频接口
   - 确认VGA信号（HSYNC, VSYNC, RGB）引脚与开发板VGA接口匹配
   - 确认七段数码管引脚已分配

4. 编译与烧录
   在Quartus中执行：
   1. Processing -> Clean Project（每次修改.mif后必须执行！）
   2. Processing -> Start Compilation
   3. Tools -> Programmer -> 选择USB-Blaster -> Start

5. 硬件连接
   PS2键盘      插入开发板PS2接口
   VGA显示器    标准VGA线缆连接
   音频输出     板载蜂鸣器自动发声
   辅助显示     板载七段数码管自动显示分数

================================================================================
关键设计约束
================================================================================

以下约束来自团队硬件调试经验，请务必遵守。

.mif 纯净格式      地址范围不可重叠，Quartus 13.1 解析器对此极其严格
BLOCK_SHIFT = 3    固定对应 8x8 像素格子，不可更改
4级流水线          MAP.v 中的数据必须严格按拍传递，禁止跨级组合逻辑
边界保护           地图越界检查需同步更新 curr_width / curr_height
Clean Project      每次修改 .mif 后必须 Clean Project 再编译，否则缓存读取旧版地图

================================================================================
核心模块说明
================================================================================

PS2_Keyboard_Controller.v
  接收PS2协议串行数据，解析扫描码（Scan Code Set 2）
  输出按键状态信号，供Input_Controller进行游戏逻辑映射

Input_Controller.v
  将PS2扫描码转换为游戏控制信号
  输出方向键与暂停键的脉冲/电平信号

MAP.v
  第1级：读取 maze_map.mif，获取当前区块编号
  第2级：根据编号选择精灵数据（墙、豆子、空路、角色）
  第3级：精灵像素颜色查表（rom_wall / rom_pacman / rom_ghost）
  第4级：RGB输出至VGA DAC

Music_Player.v
  基于计数器分频产生PWM音频信号
  支持多种音效：吃豆音效、死亡音效、背景音乐

LFSR.v
  线性反馈移位寄存器伪随机数生成器
  为幽灵AI提供不可预测的移动决策种子

已知问题与解决
================================================================================

现象                原因                              解决方案
------------------- --------------------------------- -----------------------------------------
烧录后穿墙          时序约束不足或.mif缓存未刷新       更新SDC文件，严格遵循"Clean Project -> 编译"流程
地图显示错乱        拨动开关编码与.mif文件不对应       检查 game_defines.v 中难度映射表
音乐无声            音频引脚未绑定或PWM频率超出范围     检查Pin Planner，确认蜂鸣器支持频率
PS2键盘无响应       PS2时钟未正确接入或协议解析错误     用示波器检查PS2_CLK信号，确认键盘供电正常
